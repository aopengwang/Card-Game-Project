# Background music

Put audio files in this folder. Every player can then pick one (or "Play all") under
**Settings → Background music**. No rebuild or restart is needed: reopen Settings.

- **Formats:** `.mp3`, `.ogg`, `.opus`, `.m4a`, `.aac`, `.wav`, `.flac`. MP3 and M4A work
  in every browser.
- **Names:** the file name is the title players see, so `Mountain_Rain.mp3` shows as
  "Mountain Rain". Chinese file names work too.
- **Subfolders** aren't read.

Each player chooses for themselves: your choice doesn't change what others hear.

Online (Render), only files committed to the repository are deployed. Keep them small
(a few MB each), and only add music you're allowed to share.
